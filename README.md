# Express.js Middleware Practice

Simple practice assignment using Express.js.

## 🚀 What This Project Does

- Initializes an Express.js app
- Adds two middleware functions that log each request
- Handles two routes: `/` and `/users`, each with a simple response

## 📚 Based On

This assignment is based on a practice task from the [Udemy course](https://www.udemy.com/course/nodejs-the-complete-guide/)  
📘 **"NodeJS - The Complete Guide (MVC, REST APIs, GraphQL, Deno)"** by Academind

## 🛠️ How to Run

```bash
npm install
npm start
```
